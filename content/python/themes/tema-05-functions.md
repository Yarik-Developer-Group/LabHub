## План заняття

1. Введення у функції: `def` та `return`.
2. Області видимості: local, global, nonlocal.
3. Аргументи, передача аргументів у функції.

## Шпаргалка: області видимості (LEGB)

Python шукає ім'я змінної у чотирьох вкладених «шарах» — зсередини
назовні:

```
+-------------------------------------------------------------+
| Вбудована область видимості (Builtins)                      |
| Імена, попередньо присвоєні в модулі builtins:               |
| open, range, SyntaxError...                                  |
|  +--------------------------------------------------------+ |
|  | Глобальна область видимості (модуль)                   | |
|  | Імена, присвоєні на верхньому рівні файлу модуля або   | |
|  | оголошені глобальними в операторі def всередині файлу. | |
|  |  +---------------------------------------------------+ | |
|  |  | Локальні області видимості охоплюючих функцій     | | |
|  |  | Імена в локальній області видимості будь-яких     | | |
|  |  | охоплюючих функцій (def або lambda), від          | | |
|  |  | найглибшої до зовнішньої.                         | | |
|  |  |  +----------------------------------------------+ | | |
|  |  |  | Локальна область видимості (функція)         | | | |
|  |  |  | Імена, так чи інакше присвоєні всередині     | | | |
|  |  |  | функції (def або lambda) і не оголошені      | | | |
|  |  |  | глобальними в цій функції.                   | | | |
|  |  |  +----------------------------------------------+ | | |
|  |  +---------------------------------------------------+ | |
|  +--------------------------------------------------------+ |
+-------------------------------------------------------------+
```

## Задачі на основи написання функцій

Усі розв'язки задач необхідно оформлювати у вигляді відповідних функцій.
Введення та виведення даних повинні здійснюватися в основній частині
програми через стандартні потоки введення-виведення.

**Задача 1. Мінімум 4 чисел.** Напишіть функцію
`min(a, b, c, d)`, яка знаходить найменше з чотирьох даних чисел.

*Вхідні дані:* вводиться чотири числа.

*Вихідні дані:* необхідно вивести найменше з 4-х даних чисел.

Приклад. Вхідні дані:

```
4 5 6 7
```

Вихідні дані:

```
4
```

**Задача 2. Голосування.** Напишіть «функцію голосування»
`election(x, y, z)`, яка повертає те значення (`true` або `false`), яке
серед значень її аргументів x, y, z зустрічається частіше.

*Вхідні дані:* вводиться 3 числа — x, y і z (x, y і z дорівнюють 0
або 1; 0 відповідає значенню `false`, 1 відповідає значенню `true`).

*Вихідні дані:* необхідно вивести значення функції від x, y і z.

Приклад. Вхідні дані:

```
0 0 1
```

Вихідні дані:

```
0
```

**Задача 3. Перевірка на простоту.** Перевірте, чи є число простим.

*Вхідні дані:* вводиться одне натуральне число n, що не перевищує
2000000000 і не дорівнює 1.

*Вихідні дані:* необхідно вивести рядок `prime`, якщо число просте,
або `composite`, якщо число складене.

Приклад. Вхідні дані:

```
5
```

Вихідні дані:

```
prime
```

**Задача 4\*. Мінімум з довільної кількості різних чисел.** На вхід
функції подається випадкова кількість різних цілих чисел. Знайдіть
максимальне серед переданих чисел.
