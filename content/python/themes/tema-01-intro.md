## Робота з виводом на консоль

Вивести на консоль наступні рядки:

```
"Вітаю!" - сказав я, поглянувши на годинник.
"Як що не складно, прошу звернути увагу на \ документ," - додав я. Було
незрозуміло, що відбувається, але все стало на місця після аналізу.
\Залишалося тільки зібратисі продовжити роботу...\
```

Давай спробуємо надрукувати інформацію про вивчені спецсимволи:

```
\t - табуляція;
\n - перенос рядка;
```

Сьогодні ми провели наше перше заняття, почали вивчати основи мови
програмування Python. За сьогодні ми навчилися працювати з:

```
рядками (наприклад: "рядок1", "рядок2");
числами (наприклад: 5, -3.14);
розв'язали різні геометричні задачі.

Наприкінці заняття плануємо познайомитися зі змінними.
```

## Практика

**Ділення яблук.** N школярів ділять K яблук порівну, залишок, що не
ділиться, залишається в кошику. Скільки яблук дістанеться кожному
школяреві? *Вхідні дані:* числа N і K. *Вихідні дані:* кількість яблук.

**Ділення яблук 2.** N школярів ділять K яблук порівну, залишок, що не
ділиться, залишається в кошику. Скільки яблук залишиться у кошику?
*Вхідні дані:* числа N і K. *Вихідні дані:* кількість яблук.

**Остання цифра.** Дано натуральне число. Виведіть останню цифру.

**Залишок від поділу.** Вивести усі цифри двозначного числа. Число
десятків будь-якого числа? Вивести усі цифри тризначного числа. Вивести
суму цифр тризначного числа.

**Наступне парне.** Дано ціле число n. Виведіть наступне за ним парне
число. При вирішенні цього завдання не можна використовувати умовну
інструкцію if та цикли.

**Котра година?** Дано число n. З початку доби минуло n хвилин.
Визначте, скільки годин і хвилин показуватиме електронний годинник
у цей момент. Програма має вивести два числа: кількість годин (від 0
до 23) та кількість хвилин (від 0 до 59). Врахуйте, що число n може
бути більше, ніж кількість хвилин на добу.

**Що покаже електронний годинник?** Електронний годинник показує час
у форматі годин, хвилин та секунд. З початку доби минуло n секунд.
Виведіть, що покаже годинник.

**Обмін значень місцями.** Напишіть програму, яка зчитує значення двох
цілих змінних a і b, потім міняє їх значення місцями. Потім виведіть
значення змінних.

*Примітка.* Розв'язанням задачі **не є** такий код:

```python
a = input()
b = input()
print(b, a)
```

Тобто ваша програма повинна мати приблизно такий вигляд:

```python
a = input()
b = input()
# Допишіть сюди
# свій код
print(a, b)
```

**Вартість покупки.** Пиріжок у їдальні коштує a гривень і b копійок.
Визначте, скільки гривень та копійок потрібно заплатити за n пиріжків.
*Вхідні дані:* три числа a, b, n. *Вихідні дані:* два числа — вартість
покупки у гривнях та копійках.

**Розрахувати решту.** Покупка коштує a гривень b копійок. За цю покупку
клієнт заплатив c гривень та d копійок. Виведіть решту, яку продавець
повинен видати покупцю.

**Різниця часу.** Дано значення двох моментів часу, що належать до
однієї і тієї ж доби: години, хвилини і секунди для кожного з моментів.
Відомо, що другий момент настав не раніше першого. Визначте, скільки
секунд пройшло між двома моментами часу.

**Завдання 2.** N піратів (N-1 пірат і капітан) знайшли скарб на острові
у розмірі K золотих. Спершу вони розділили максимальну кількість монет
між собою порівну, а весь залишок дістався капітану (понад частину, що
йому належить). Скільки монет дісталося звичайному пірату? А капітанові?
Вивести два числа в один рядок через пропуск.

Наприклад: 5 піратів (N=5) знайшли 23 монети (K=23). Тоді кожен пірат
отримає по 4 монети (у тому числі і капітан), а потім капітану дісталося
ще 3 монети, що залишилися. Очікувана відповідь: `4 7`

Програма має видавати правильний результат незалежно від значень N, K.

Ви намагаєтесь отримати N копійок. Яку мінімальну та максимальну
кількість монет може видати банкомат? Вивести 2 числа через пробіл.
Наприклад: N = 23 → відповідь `7 23`.

**Завдання 6.** Дано число N. Вивести дві останні цифри числа

**Завдання 7.** На годиннику N годин і M хвилин. Скільки секунд минуло
від початку доби? Наприклад: N = 1, M = 20 → 4800 секунд.

**Завдання 8.** Перегляд однієї серії серіалу займає K хвилин. Скільки
