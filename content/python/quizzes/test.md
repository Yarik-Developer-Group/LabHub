Пишеться без комп'ютера. У питаннях з варіантами одна правильна
відповідь; у блоках А і Б відповідь записується словами.

але спочатку напишіть, потім звіряйтеся.

## Блок А. Що виведе код?

Для кожної програми запишіть, що саме вона виведе на консоль
(включно з порядком і кількістю рядків).

**1.**

```python
print(17 // 5, 17 % 5)
```

**2.**

```python
x = "5"
print(x * 3)
```

**3.**

```python
a = 3
b = 10
if a > 5 or b // a == 3:
    print("так")
else:
    print("ні")
```

**4.**

```python
s = 0
for i in range(2, 7, 2):
    s += i
print(s)
```

**5.**

```python
n = 4
while n > 0:
    n -= 2
    print(n)
```

**6.**

```python
N = [3, 6, 9]
print(N[-1] + N[0])
```

**7.**

```python
M = [[1, 2], [3, 4], [5, 6]]
print(M[1][0] + M[2][1])
```

**8.**

```python
def f(a, b=2):
    return a * b

print(f(3), f(3, 3))
```

## Блок Б. Знайди помилку

У кожній програмі є рівно одна помилка. Вкажіть рядок і поясніть,
що саме піде не так (виняток чи неправильний результат).

```python

```

**10.** Програма має вивести всі елементи списку.


**11.** Програма має порахувати кількість ітерацій циклу.

```python

    count = 1
print(count)
```

## Блок Д. Перевір ШІ

У кожному завданні цього блоку наведено умову задачі та розв'язок,
згенерований штучним інтелектом. Розв'язок проходить приклад з умови,
але містить помилку. Знайдіть її: вкажіть вхідні дані, на яких програма
дасть неправильну відповідь, і поясніть чому.

**33.** *Умова:* знайти суму всіх парних чисел від 1 до N включно.
*Приклад:* N = 5 → відповідь 6 (2 + 4).

```python
n = int(input())
s = 0
for i in range(1, n):
    if i % 2 == 0:
        s += i
print(s)
```

**34.** *Умова:* знайти найбільший елемент у списку чисел.
*Приклад:* [3, 1, 7, 2] → відповідь 7.

```python
numbers = [int(x) for x in input().split()]
maximum = 0
for x in numbers:
    if x > maximum:
        maximum = x
print(maximum)
```

**35.** *Умова:* порахувати кількість слів у рядку. Словом вважається
послідовність символів, відмінних від пробілу.
*Приклад:* `I live in Kyiv.` → відповідь 4.

```python
s = input()
print(len(s.split(" ")))
```
