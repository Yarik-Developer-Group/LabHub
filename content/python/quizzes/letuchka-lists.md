## Варіант 1

**Завдання 1.** Дано список `N = [1, 2, 34, 5678]`. Чому дорівнюватиме
елемент з індексом -4?

- a) виняток (exception)
- b) 1
- c) 34
- d) 5678

**Завдання 2.** Дано список `N = [6, 5, 2, 16, 10, 5]`. За яким індексом
знаходиться число 5?

- a) 2
- b) 5
- c) 0
- d) 6

**Завдання 3.** Який зі способів змінити елемент списку `N = [1, 5, 3, 4]`
викличе помилку?

- a) `N[-1] = 2`
- b) `N[4] = 2`
- c) `N[2] = "raw"`
- d) `N[0] = N[2]`

**Завдання 4.** Визначити, що робить наступний скрипт (що саме він
виведе):

```python
N = [1, 3, 5, 7, 10, 12]
for i in range(len(N)):
    if i % 2 == 0:
        print(N[i])
```

**Завдання 5.** Визначити ВСІ істинні твердження.

- a) У мові програмування Python звернення до елемента списку
  за неіснуючим індексом призводить до винятку
- b) У мові програмування Python не існує способу видалити або додати
  нові елементи до списку
- c) Індекс списку повинен бути цілим числом
- d) Більшість мов програмування підтримують масиви (списки) в тому
  чи іншому вигляді

- a) не існує такого елемента у списку
