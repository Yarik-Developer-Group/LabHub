## Перевір ШІ

41. `range(1, n)` не включає n, тому при парному N губиться саме N.
    Контрприклад: N = 6 → програма виведе 6 (2+4), а правильно
    12 (2+4+6). Приклад з умови (N = 5, непарне) проходить випадково.
42. `maximum = 0` — стартове значення «з повітря». На списку, де всі
    числа від'ємні, жоден елемент не більший за 0, і програма виведе 0.
    Контрприклад: `[-5, -2, -9]` → виведе 0, а правильно -2. Стартувати
    треба з першого елемента списку.
43. `split(" ")` ріже строго по одному пробілу: подвійні пробіли
    та пробіли на краях дають порожні «слова». Контрприклад:
    `"  I  live  "` → відповідь 7 замість 2. Правильно — `split()`
    без аргументу.
