## Блок А. Що виведе код?

1. `3 2` — цілочисельна частка і залишок від 17 / 5.
2. `555` — множення рядка на число повторює рядок.
3. `так` — `a > 5` хибне, але `b // a` = 10 // 3 = 3, тож or істинний.
4. `12` — range(2, 7, 2) дає 2, 4, 6.
5. Два рядки: `2`, потім `0` — n зменшується ДО print, а при n = 0 цикл
   зупиняється.
6. `12` — N[-1] = 9 (останній), N[0] = 3.
7. `9` — M[1][0] = 3, M[2][1] = 6.
8. `6 9` — перший виклик бере b = 2 за замовчуванням, другий передає
   b = 3.

## Блок Б. Знайди помилку

9. `input()` повертає **рядок**, а рядок не можна порівнювати з числом
   через `>` — TypeError на другому рядку. Треба `x = int(input())`.
10. На останній ітерації i = 2, а `N[i + 1]` — це N[3], якого
    не існує — IndexError. Треба `print(N[i])`.
11. `count = 1` замість `count += 1` — програма завжди виводить 1,
    скільки б ітерацій не було. Винятку немає, помилка логічна.

## Блок В. Читання чужого коду

12. **c** — порівняння у Python — це `==`.
13. **a** — у C істинність числа означає «не нуль», тож `y` → `y != 0`.
14. **d** — `System.out.print`.
15. **c** — `$x = 5;`.
16. **a** — Length — довжина рядка, тобто кількість символів.

## Блок Г. Концепти

17. **a** — інтерпретована.
18. **c** — float.
19. **a** — input() і так повертає рядок, str зайвий.
20. **a** — ім'я не може починатися з цифри.
21. **b** — `2*"5"` дасть `"55"` (повторення рядка); решта — винятки.
22. **a** — степінь → множення → віднімання.
23. **d** — блок живлення дає енергію, дані не зберігає; процесор
    зберігає у регістрах і кеші.
24. **b** — у Python (та інших динамічних мовах) тип не вказується.
25. **c** — do while у Python немає.
26. **c** — `or` істинний майже завжди (наприклад, x=1000, a=0, b=5),
    це не перевірка «між».
27. **b** — навпаки: elif може бути декілька, else — щонайбільше один.
28. **b** — елементи списку якраз змінювані.
29. **b** — `-len(N)` — це перший елемент; `len(N)` — вихід за межу,
    `-len(N)-1` — теж, `len(N)/2` — float → TypeError.
30. **c** — 3 параметри (два з них — зі значеннями за замовчуванням).
31. **a** — навпаки: що менше параметрів, то краще.
32. **d** — `from * import fileName` — синтаксична нісенітниця
    (правильно: `from fileName import *`).

## Блок Д. Перевір ШІ

33. `range(1, n)` не включає n, тому при парному N губиться саме N.
    Контрприклад: N = 6 → програма виведе 6 (2+4), а правильно
    12 (2+4+6). Приклад з умови (N = 5, непарне) проходить випадково.
34. `maximum = 0` — стартове значення «з повітря». На списку, де всі
    числа від'ємні, жоден елемент не більший за 0, і програма виведе 0.
    Контрприклад: `-5 -2 -9` → виведе 0, а правильно -2. Стартувати
    треба з першого елемента списку.
35. `split(" ")` ріже строго по одному пробілу: подвійні пробіли
    та пробіли на краях дають порожні «слова». Контрприклад:
    `"  I  live  "` → відповідь 7 замість 2. Правильно — `split()`
    без аргументу.
