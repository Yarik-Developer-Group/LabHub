**Як мінімум у двох задачах провести максимально повну
валідацію/перевірку вхідних даних.**

**Завдання 1.** Дано два цілих числа N і M. Програма повинна вивести
число 1, якщо перше число більше другого, число 2, якщо друге більше
першого, або число 0, якщо вони рівні.

Приклади:

- N = 5, M = 3 → відповідь: 1
- N = 3, M = 5 → відповідь: 2
- N = 2, M = 2 → відповідь: 0

**Завдання 2.** Шаховий кінь знаходиться на позиції (a, b). Треба
визначити, чи б'є він фігуру, що стоїть на позиції (c, d), і якщо це
так — вивести `YES`, у протилежному випадку `NO`.

Приклади:

- a = 2, b = 2, c = 3, d = 4 → відповідь: `YES`
- a = 2, b = 2, c = 3, d = 5 → відповідь: `NO`

**Завдання 3.** Король стоїть на позиції (a, b). Вивести всі
координати, на які він може піти за 1 хід (порядок перелічення полів
значення не має).

Приклад: a = 1, b = 2. Відповідь:

```
(1, 1)
(1, 3)
(2, 1)
(2, 2)
(2, 3)
```

**Завдання 4.** Програма отримує на вхід два числа a та b. Вивести
розв'язок рівняння ax + b = 0, якщо він є; `NO` — якщо розв'язків
немає; `INF` — якщо число розв'язків нескінченне.

Приклади:

- a = 1, b = 2 → відповідь: -2
- a = 0, b = 2 → відповідь: `NO`
- a = 0, b = 0 → відповідь: `INF`

**Завдання 5.** Покупка обійшлася в a доларів та b центів. За неї
заплатили c доларів і d центів. Визначити розмір решти, яку повинен
видати продавець.

Приклади:

- a = 1, b = 2, c = 2, d = 30 → відповідь: `1 $ 28 c`
- a = 1, b = 20, c = 1, d = 20 → відповідь: `0 $ 0 c`

**Завдання 6.** Дано три числа a, b і c. Визначити, чи існує трикутник
з такими сторонами. Вивести `YES`, якщо існує, у протилежному
випадку — `NO`.

**Завдання 7.** N школярів ділять K яблук «порівну», тобто так, щоб
кількість яблук, які дісталися будь-яким двом школярам, відрізнялася
не більше ніж на 1.

Програма повинна вивести кількість школярів, яким дістанеться яблук
менше, ніж деяким з їхніх товаришів.

Приклади:

- N = 5, K = 12 → відповідь: 3
- N = 4, K = 12 → відповідь: 0
