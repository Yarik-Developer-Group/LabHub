`*` — завдання підвищеної складності.

**Завдання 1 (for), 2 (while).** На вхід подається єдине число N.
Знайти суму квадратів усіх непарних чисел, менших за N.

Задачу розв'язати два рази (перший — за допомогою циклу `for`, другий
раз — використовуючи цикл `while`).

Приклади:

- N = 6 → відповідь: 35 (1² + 3² + 5² = 35);
- N = 7 → відповідь: 35 (1² + 3² + 5² = 35);
- N = 8 → відповідь: 84 (1² + 3² + 5² + 7² = 84).

**Завдання 3 (for), 4 (while).** Вводиться єдине число N. Обчислити
наступну суму: $2^1 + 2^2 + 2^3 + \ldots + 2^N$

Задачу розв'язати два рази (перший — за допомогою циклу `for`, другий
раз — використовуючи цикл `while`).

Приклади:

- N = 4 → відповідь: 30 (2¹ + 2² + 2³ + 2⁴ = 30);
- N = 6 → відповідь: 126 (2¹ + 2² + 2³ + 2⁴ + 2⁵ + 2⁶ = 126).

**Завдання 5.** На вхід подається єдине число N. Знайти добуток усіх
чисел, квадрат яких менший за N.

Приклади:

- N = 19 → відповідь: 24 (1\*2\*3\*4 = 24, оскільки 4² все ще менше
  за 19, а от 5² вже більше);
- N = 16 → відповідь: 6 (1\*2\*3 = 6, оскільки 3² все ще менше за 16,
  а от 4² вже більше або дорівнює).

**Завдання 6\*.** На вхід подається єдине число N. Знайти добуток усіх
чисел, модуль яких менший або дорівнює N (виключаючи 0).

Приклади:

- N = 3 → відповідь: -36 ((-3)\*(-2)\*(-1)\*1\*2\*3 = -36);
- N = 2 → відповідь: 4 ((-2)\*(-1)\*1\*2 = 4).

**Завдання 7.** За даним числом N надрукуйте всі цілі степені двійки,
що не перевищують N, у порядку зростання.

Приклади:

- N = 19 → відповідь: 1 2 4 8 16
- N = 32 → відповідь: 1 2 4 8 16 32

**Завдання 8.** Дано натуральне число N. Виведіть слово `YES`, якщо
число N є точним степенем двійки, або слово `NO` у протилежному
випадку.

Приклади:

- N = 16 → відповідь: `YES`
- N = 31 → відповідь: `NO`

**Завдання 9\*.** Виконавець «Роздвоювач» перетворює натуральні числа.
У нього є дві команди: «Відняти 1» та «Поділити на 2». Перша команда
зменшує число на 1, друга команда зменшує число вдвічі, якщо воно
парне, інакше виникає помилка.

*Вхідні дані:* дано два натуральні числа A і B (A > B).

*Вихідні дані:* напишіть алгоритм для «Роздвоювача», який перетворює
число A на число B і при цьому містить мінімальне число команд. Команди
алгоритму потрібно виводити по одній у рядку: перша команда
позначається як `-1`, друга — як `:2`.

**Завдання 10.** Програма отримує на вхід послідовність цілих
невід'ємних чисел, кожне число записано в окремому рядку.
Послідовність завершується числом 0, при зчитуванні якого програма
повинна закінчити свою роботу. Числа, що йдуть за числом 0, зчитувати
не потрібно. Визначте середнє арифметичне елементів послідовності, яка
завершується числом 0 (число 0 до послідовності не входить).

Приклади:

- вхід: `0` → відповідь: 0;
- вхід: `1 3 8 0` (по одному в рядку) → відповідь: 4
  ((1+3+8) / 3 = 4 — ділимо на три, оскільки було введено три
  елементи: 1, 3 і 8; 0 — не враховується).

**Завдання 11.** Вводиться єдине число x. Знайти добуток його цифр.

Приклад: x = 124 → відповідь: 8 (1\*2\*4 = 8).

**Завдання 12.** Вводиться єдине число x. Знайти добуток усіх його
цифр, відмінних від 0.

Приклад: x = 12405 → відповідь: 40 (1\*2\*4\*5).
