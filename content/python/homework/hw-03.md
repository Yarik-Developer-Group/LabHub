**Завдання 1.** Дано число N. Вивести слово `Positive`, якщо воно
додатне або дорівнює нулю, в іншому випадку вивести слово `Negative`.

Для розв'язання задачі використати оператор `if`.

Приклади:

- N = 5 → відповідь: `Positive`
- N = 0 → відповідь: `Positive`
- N = -5 → відповідь: `Negative`

**Завдання 2.** Дано два числа a і b. Вивести їх добуток, якщо їх сума
дорівнює нулю. В протилежному випадку вивести квадрат суми чисел a та b.

Приклади:

- a = 2, b = -2 → відповідь: -4 (оскільки -2 \* 2 = -4);
- a = 2, b = 3 → відповідь: 25 (оскільки (2+3)² = 25).

**Завдання 3.** Дано два числа M і N. Вивести залишок від поділу M
на N, якщо він не дорівнює 0. У протилежному випадку нічого
не виводити.

**Завдання 4.** Від початку доби пройшло N секунд. Виведіть, який час
зараз показує годинник.

Приклади:

- N = 62 → відповідь: `0 : 1 : 2` (0 годин 1 хвилина 2 секунди);
- N = 3734 → відповідь: `1 : 2 : 14` (1 година 2 хвилини 14 секунд).
