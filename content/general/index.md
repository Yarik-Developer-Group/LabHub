Матеріали, які не належать жодному конкретному курсу: інструменти
розробника та здача робіт через pull request.

## Інструменти розробника

Роботи здаються через pull request, тому знадобиться git і хмарний сервіс
для збереження коду:

- **Git for Windows**: [git-scm.com/download/win](https://git-scm.com/download/win)
- **Bitbucket** (сервіс для збереження коду у хмарі):
  [bitbucket.org](https://bitbucket.org/) — **або**, як альтернатива,
  [GitHub](https://github.com/). Достатньо одного, на ваш вибір.
