## Провайдери баз даних

Реляційних СУБД багато: **MS SQL Server**, **PostgreSQL**, **MySQL/MariaDB**,
**Oracle**, **SQLite**. Для нашого курсу підійде майже будь-яка «серверна» —
ви обираєте між MS SQL Server та PostgreSQL на початку семестру.

Окремо про **SQLite**: це вбудована однокористувацька база — файл поруч
з додатком, без сервера. Ідеальна для мобільного застосунку чи локальної
програми, але для багатокористувацьких систем (а ми вчимося саме таким)
вона не призначена.

Продуктивність бази впирається не туди, куди здається на перший погляд —
про це окремі сторінки: [Архітектура ПК](/c/general/pc-architecture)
та [Що із заліза важливо для БД](/c/databases/theory/hardware-for-db).

## Що встановити

Вам знадобиться **одна** СУБД на весь семестр — встановлювати обидві
не потрібно. Нижче — **рекомендовані** варіанти; якщо хочете працювати
з іншою СУБД (MySQL, Oracle тощо) — я не обмежую, просто узгодьте
це з викладачем:

**Варіант А — MS SQL Server:**

- [SQL Server Database Engine](https://learn.microsoft.com/en-us/ssms/install/install) — сам сервер;
- [SSMS](https://aka.ms/ssms/21/release/vs_SSMS.exe) — IDE для роботи з ним.

**Варіант Б — PostgreSQL:**

- [Інсталятор для Windows](https://www.postgresql.org/download/windows/) —
  сервер разом з pgAdmin (IDE) в одному пакеті.

Інструменти розробника (git, Bitbucket/GitHub) та покрокові інструкції
зі здачі робіт — у розділі [«Загальне»](/c/general).
