Теми для вивчення перед [ПР2](/c/databases/practice/pr-02-table-and-queries):

- Типи даних MS SQL Server: числові (`int`, `bigint`, `decimal`), рядкові
  (`varchar` vs `nvarchar`), дати й час (`date`, `datetime2`), `bit`, `uniqueidentifier`.
  Що шукати: *SQL Server data types best practices*.
- Обмеження цілісності: `NULL`/`NOT NULL`, `DEFAULT`, `PRIMARY KEY`, `UNIQUE`,
  `CHECK`. Що шукати: *SQL Server constraints*.
- Обчислювані колонки. Що шукати: *computed columns SQL Server, persisted*.
- Базові оператори: `SELECT`, `INSERT`, `UPDATE`, `DELETE`, а також
  `TOP`, `OFFSET/FETCH`, `ORDER BY`, `LIKE`, `IN`, `IS NULL`, `BETWEEN`,
  логічні `AND`/`OR`/`NOT`.
- Цикл `WHILE` у T-SQL — для генерації тестових даних.
