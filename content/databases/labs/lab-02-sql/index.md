## Цель

Реализовать схему из лабы 1 в реальной СУБД (MS SQL или PostgreSQL — на выбор)
и научиться доставать из неё данные.

## Задание

1. Напишите DDL для всех таблиц вашей схемы (ключи, ограничения, индексы).
2. Наполните таблицы тестовыми данными (по 10–20 строк).
3. Напишите и выполните запросы:

```sql
-- топ-5 клиентов по сумме заказов
SELECT TOP 5 c.name, SUM(oi.qty * p.price) AS total
FROM customers c
JOIN orders o      ON o.customer_id = c.id
JOIN order_items oi ON oi.order_id = o.id
JOIN products p    ON p.id = oi.product_id
GROUP BY c.name
ORDER BY total DESC;
```

4. Добавьте свой запрос с `LEFT JOIN`, у которого есть осмысленная бизнес-формулировка.

Скрипт DDL + скрипты запросов + скриншоты результатов.
