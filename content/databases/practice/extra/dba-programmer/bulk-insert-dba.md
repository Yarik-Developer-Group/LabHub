## Мета

Навчитися вантажити великі обсяги даних у базу штатними механізмами СУБД,
не написавши жодного рядка коду додатка.

## Перед виконанням

- MS SQL: `BULK INSERT` та утиліта `bcp`.
- PostgreSQL: команда `COPY` (і `\copy` у psql).
- Вплив розміру батча на швидкість завантаження.

## Завдання

1. Згенеруйте CSV-файл зі **100 000+** рядків для вашої сутності
   (будь-яким способом — хоч скриптом, хоч тим самим генератором з ПР3
   з вивантаженням).
2. Завантажте його у таблицю штатним bulk-механізмом вашої СУБД.
   Заміряйте час.
3. Для порівняння: завантажте той самий файл звичайними INSERT-ами
   (можна згенерувати скрипт). Заміряйте.
4. Поекспериментуйте з розміром батча у bulk-завантаженні —
   покажіть його вплив на час.
5. Табличка замірів + висновок на пару речень.

## Як здавати

Pull request зі скриптами, командами завантаження та таблицею замірів.
