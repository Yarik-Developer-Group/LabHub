summary: Необов'язкові роботи за напрямами — обирайте гілку, яка ближча до вашого майбутнього.
---

Роботи цього розділу **не є обов'язковими** — це додатковий матеріал для тих,
хто хоче більше. Вони згруповані за напрямами розвитку:

- **Спільне** — фундамент, корисний усім незалежно від напряму.
- **Розробник** — для тих, хто писатиме додатки поверх баз даних.
- **DBA-програміст** — для тих, кому цікавий складний SQL.
- **DBA-адміністратор** — для тих, хто триматиме сервер живим.

Виконувати можна будь-які роботи з будь-яких гілок у будь-якому порядку —
якщо у самій роботі не сказано інше. Здача — як завжди: pull request
і «прийнято».
