## Мета

Обгорнути таблицю з [ПР2](/c/databases/practice/pr-02-table-and-queries)
програмованими об'єктами бази даних.

## Перед виконанням

Теми, які варто розібрати:

- Уявлення (`VIEW`): навіщо потрібні, чим відрізняються від таблиці.
  Що шукати: *SQL Server views*.
- Функції: скалярні та табличні, у чому різниця і коли яку обирати.
  Що шукати: *scalar vs table-valued function*.
- Збережені процедури, параметри та значення за замовчуванням.
  Що шукати: *stored procedure optional parameter*.
- Тригери `AFTER INSERT/UPDATE/DELETE`, службові таблиці `inserted` і `deleted`.
  Що шукати: *SQL Server trigger inserted deleted*.
- `UNION` та `UNION ALL` — і чим вони відрізняються (це питання люблять
  на співбесідах).

## Завдання

На основі створеної таблиці:

1. Створити **уявлення (view)**, яке відображає якийсь бізнес-процес
   вашого варіанта.
2. Створити **скалярну** та **табличну функції** — теж із бізнес-змістом,
   а не «аби було».
3. Створити **процедуру для генерації нових даних**: опціональний параметр
   задає кількість рядків, які треба згенерувати.
4. Створити **таблицю для ведення історії** змін і **тригер**, який її заповнює.
5. Використовуючи `UNION ALL` (або `UNION`) вивести інформацію про **існуючі
   та видалені** сутності/рядки системи одним результатом.
